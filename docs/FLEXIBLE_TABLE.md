# Гибкая таблица: версия 2.0

Пользователь одобрил макет 11 сентября 2026 года и уточнил: группы фильтров
должны сворачиваться, таблица должна быть большой и удобной. Разрешены
разработка, проверки, публикация и повторная проверка публичной версии.

Версия опубликована; [итоговый протокол](DEPLOYMENT_V2.md) и [проверенный откат](ROLLBACK.md).
Текущая визуальная система зафиксирована в [DESIGN.md](../DESIGN.md).

## Принятые решения

- Сохраняется визуальный язык SportGen: светлая поверхность, тёмная зелёная
  шапка, IBM Plex Sans, зелёные галочки, оранжевая основная кнопка.
- Рабочая таблица занимает всю ширину. Панель поиска и её подразделы — native
  details/summary. После поиска панель сворачивается. Есть полноэкранный режим.
- Конструктор содержит девять групп с галочками, поиск по полям, групповой
  выбор, список порядка с перетаскиванием и кнопками для клавиатуры/телефона.
- Черновик отделён от применённого набора. Предпросмотр использует текущие
  статьи или явно помеченный синтетический пример. Пустой черновик не применяется.
- Шаблоны хранятся только в браузере; JSON позволяет переносить их. Архив
  сеанса содержит применённые колонки и остаётся совместимым со старой схемой.
- Для других исследовательских тем снято обязательное сочетание генетики и
  спорта. OpenAlex поддерживает российский и глобальный охват.
- 18 новых полей увеличили таблицу до 69 колонок. Извлечение основано на
  ограниченных словарях и правилах; значения сопровождаются исходным текстом.
- Одна строка остаётся статьёй. Поля сохраняют несколько исходных формулировок;
  приложение не создаёт фиктивные пары клеточных линий, молекул и результатов.
- CSV/XLSX могут учитывать все строки после фильтрации и их сортировку.
  JSON всегда сохраняет полный сеанс, независимо от фильтра таблицы.

## Проверки

Команды для автоматических проверок:

```sh
Rscript tests/run_tests.R
Rscript tests/server_flow.R
Rscript tests/validate_corpus.R
Rscript tests/run_live_tests.R
Rscript tests/live_flexible.R
```

Браузерный прогон использует Python Playwright и Chromium. Он проверяет
выбор полей, порядок, шаблоны, перезагрузку, импорт архивов, фильтрацию,
сортировку, CSV/XLSX, пустую выдачу, компактность, полноэкранный режим,
ручную проверку новых полей и повторное извлечение. Скриншоты снимаются до
и после действий, на настольной и мобильной ширине.

Синтетическая фикстура для браузера должна содержать 30 статей с заголовками
`Synthetic QA`, чередовать MCF-7/miR-21 и A549/miR-34a и сохранять столбцы
`title, year, disease, cell_line, mirna, assay_method`. Она не представляет
реальные научные выводы и используется только для проверки взаимодействий.

```sh
Rscript tests/create_browser_fixture.R
python3 tests/browser_flow.py --archive out/browser_fixture.json
```

Локальный внешний vision-сервис `127.0.0.1:1235` недоступен. Его автоматический
статус pass не заявляется; визуальная проверка производится по скриншотам
ассистентом и отдельным рецензентом. Проверки браузером сами по себе не
являются научной валидацией извлечения.
