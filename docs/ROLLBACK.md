Исходное состояние перед новой работой: коммит `735a74d` от 5 сентября 2026 года. Он сохранён в ветке `backup/pre-flexible-20260911` локально и на GitHub. Его функциональный код соответствует проверенному релизу `561c8fa`. Новая версия состоит из коммитов `50c474f` и `4cc5f6c`; рабочая ветка — `feature/flexible-table-20260911`.

В ней находятся `repository.bundle` (Git-история до изменений), исходные README и `FULL_CONTEXT.md`, а также `commit.txt`.

## Открыть старую версию, сохранив новую

В терминале из папки проекта, после остановки локального приложения:

```sh
git status --short
git switch backup/pre-flexible-20260911
Rscript launch_app.R
```

Если после этой работы появились новые незакоммиченные изменения, сначала сохраните их отдельным коммитом либо копией. Не применяйте `reset --hard` и `clean` для обычного отката.

Для возврата к доработке:

```sh
git switch main
```

## Восстановить отдельную копию из резервного bundle

Используйте новый, ещё не существующий каталог:

```sh
git clone '/Users/daniil/Desktop/MVP спортсмены/Резервные копии/sportgen-before-flexible-20260911/repository.bundle' '../Парсинг-восстановлено'
```

Bundle содержит Git-файлы и историю, но не зависимости R, API-ключи и пользовательские выгрузки, исключённые из Git. Для установки зависимостей в восстановленной копии используется `Rscript install_packages.R`.

## Вернуть данные исследовательского сеанса

Перед новым поиском/закрытием страницы скачайте «Архив → Скачать архив JSON». Для восстановления откройте его во вкладке «Архив». CSV/XLSX предназначены для работы с таблицами; полного сохранённого текста для повторного извлечения в них нет.

«Отменить последнюю проверку» возвращает предыдущий снимок данных сеанса. Для нескольких этапов работы сохраняйте отдельные JSON-файлы. Повторное извлечение сохраняет поля со статусом ручного подтверждения и журнал проверки.

Версия 2.0 читает старые архивы, добавляя пустые новые поля. Сохраняйте оригиналы новых архивов перед откатом приложения: старая версия не поддерживает 18 новых полей и настройки колонок. Переносимые шаблоны колонок — отдельные JSON-файлы, а не архивы исследовательского сеанса.

## Откат опубликованного функционального релиза

Пока поверх релиза 2.0 не добавлены другие изменения кода, используйте отмену двух функциональных коммитов на чистой основной ветке. Сначала проверьте diff и тесты; push запускает автоматическую публикацию:

```sh
git switch main
git pull --ff-only
git status --short
git revert --no-edit 4cc5f6c 50c474f
Rscript tests/run_tests.R
git push origin main
```

Эта последовательность проверена 11 сентября 2026 года в отдельном временном Git worktree: после отмены дерево файлов точно совпало с `735a74d`, 165 тестов прежней версии прошли. История сохраняется. Документация, добавленная после этих коммитов, остаётся как протокол работы.

Дальнейшие изменения кода потребуют отдельной сверки перед откатом. После автоматической публикации проверьте публичный поиск и CSV/XLSX. Более ранняя резервная ветка `backup/pre-evidence-20260905` и её bundle также сохранены, но относятся к состоянию до сентябрьской доработки доказательств, а не к версии перед 2.0.
