# Как вернуть прежнюю версию

Исходное состояние: `main`, коммит `0a27eb6`. Доработки находятся только в локальной ветке `feature/tz-evidence-20260905`. Публичный сервис и удалённые ветки не изменялись.

Перед началом работ создана отдельная копия:

`/Users/daniil/Desktop/MVP спортсмены/Резервные копии/sportgen-before-tz-20260905/`

В ней находятся `repository.bundle` (все Git-ссылки до изменений), оригинальный `FULL_CONTEXT.md` и `status.txt`.

## Открыть старую версию, сохранив новую

В терминале из папки проекта, после остановки локального приложения:

```sh
git status --short
git switch main
Rscript launch_app.R
```

Если после этой работы появились новые незакоммиченные изменения, сначала сохраните их отдельным коммитом либо копией. Не применяйте `reset --hard` и `clean` для обычного отката.

Для возврата к доработке:

```sh
git switch feature/tz-evidence-20260905
```

## Восстановить отдельную копию из резервного bundle

Используйте новый, ещё не существующий каталог:

```sh
git clone '/Users/daniil/Desktop/MVP спортсмены/Резервные копии/sportgen-before-tz-20260905/repository.bundle' '../Парсинг-восстановлено'
```

Bundle содержит Git-файлы и историю, но не зависимости R, API-ключи и пользовательские выгрузки, исключённые из Git. Изначально незакоммиченный `FULL_CONTEXT.md` сохранён отдельно в той же резервной папке.

## Вернуть данные исследовательского сеанса

Перед новым поиском/закрытием страницы скачайте «Архив → Скачать архив JSON». Для восстановления откройте его во вкладке «Архив». CSV/XLSX предназначены для работы с таблицами; полного сохранённого текста для повторного извлечения в них нет.

«Отменить последнюю проверку» возвращает предыдущий снимок данных сеанса. Для нескольких этапов работы сохраняйте отдельные JSON-файлы. Повторное извлечение сохраняет поля со статусом ручного подтверждения и журнал проверки.
