# Сверка с исходным ТЗ

5 сентября 2026 года. Проверена доработанная локальная ветка `feature/tz-evidence-20260905`, исходные скриншоты из папки «Основная задача(картинки)» и код. Предыдущая версия `main` не изменена.

**Итог:** рабочий цикл поиска, извлечения, проверки и экспорта реализован. Безусловно объявлять исходное ТЗ выполненным на 100% нельзя: прямой ScienceDirect зависит от прав ключа, eLIBRARY не подключён, полнота научного извлечения требует экспертной проверки.

| Пункт исходной задачи | Текущее состояние | Ограничение |
|---|---|---|
| PubMed и редактирование запроса | Работает, проверен живой поиск | Квоты и покрытие NCBI |
| ScienceDirect | Адаптер ScienceDirect и Scopus/Elsevier fallback сохранены | Локального ключа нет; прямой ScienceDirect в этом прогоне не проверен |
| Доступная таблица, CSV, XLSX | Работает | На первом листе XLSX — выбранные колонки; дополнительные листы содержат ассоциации, сводку и проверку |
| Дедупликация | DOI → PMID → название, с защитой от конфликтующих идентификаторов | Исправления/разные публикации с конфликтующими ID сохраняются отдельно |
| Гены, SNP, сортировка | Аннотации, метаданные и доступные тексты; HGNC, числовая сортировка rsID | Нестандартные обозначения могут потребовать ручного дополнения |
| Российские/русские журналы | OpenAlex с тематическим фильтром | Его покрытие не равно eLIBRARY; прямой eLIBRARY не реализован |
| Библиография, тип исследования | Сохраняются; исправлена ложная классификация Clinical Trial как RCT | Метаданные источника тоже могут содержать ошибки |
| Генетические поля | Модель наследования, частоты, HWE, эффектный аллель | Отрицания HWE сохранены; сложные сравнения проверяются по оригиналу |
| Выборка | Тип, этничность, N, группы, пол, возраст, спорт | Численность отдельной группы не выдаётся за общий N; несколько групп остаются с подписями |
| Год исследования | Отдельное поле `study_period` | Не подменяется годом публикации или периодом поиска литературы в обзоре |
| Физическая активность и фенотип | Уровень/метод оценки, исход, метод измерения, ковариаты | Правила покрывают типичные формулировки, а не все способы описания |
| Результаты | OR/beta/CI/p, исходный знак сравнения, направление, размер эффекта, скорректированная значимость | Значения разных SNP не соединяются произвольно; данные сложных таблиц требуют проверки |
| G×E, множественные сравнения, мощность | Отдельные поля и фрагменты | Пропуск не означает отсутствие анализа в исследовании |
| Доступность данных | Исходная формулировка и отдельные ссылки на известные репозитории | Закрытые/неизвестные репозитории могут требовать ручного внесения |
| Предложение OpenEvidence | Прозрачный предварительный профиль и сводка; [обоснование](OPEN_EVIDENCE.md) | Не формальный GRADE, не EvidenceGrade и не клинически валидированный рейтинг |
| Восстановимость | Ветка, резервный bundle, архив данных, история и отмена проверки | Обновлённая версия пока локальная; опубликованное приложение не обновлялось |

## Исправленные ошибки

- Пустые DOI/PMID больше не присоединяют полный текст другой статьи.
- Повторный сбой загрузки страницы PubMed останавливает источник с ошибкой вместо бесконечного повтора.
- Дедупликация учитывает PMID даже при отсутствующем DOI у одного источника.
- p-value сохраняет `<`, `≤`, отрицательные beta и научную запись чисел.
- Отрицание нарушения HWE не превращается в нарушение.
- Clinical Trial, нерандомизированное исследование и протокол не становятся РКИ без основания.
- Гены и SNP извлекаются также из доступного полного текста, с ограничением на разделы; библиография исключается.
- Табличные заголовки и строки сохраняются; объединённые ячейки обозначаются как неоднозначные.
- Произвольные числа «уверенности» удалены; подтверждение поля требует основания и переживает повторное извлечение.
