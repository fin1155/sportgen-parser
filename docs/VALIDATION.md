# Протокол проверки

## Офлайн

`Rscript tests/run_tests.R` использует только фикстуры из `tests/fixtures`.
Проверяются:

- границы слов для генов и официальный словарь HGNC;
- извлечение и числовая сортировка rsID;
- форматы ответов ScienceDirect V1/V2, OpenAlex и Crossref;
- дедупликация по DOI и сохранение происхождения записи;
- секционный разбор PMC без библиографии;
- HWE, размер/пол/возраст выборки, результаты и научная запись p-value;
- защита от ложной классификации обзора как RCT;
- заполнение не-PubMed записей по аннотации;
- JSON-доказательства извлечения.

## Живые источники

`Rscript tests/run_live_tests.R` выполняет ограниченный запрос и проверяет:

1. PubMed возвращает записи с PMID и названием.
2. OpenAlex возвращает русскоязычные/российские записи и каждая проходит
   локальный тематический фильтр.
3. Crossref разрешает контрольный DOI.
4. PMC отдаёт полный текст, секции распознаются и заполняют несколько целевых
   полей.
5. Открытый полный текст, найденный через OpenAlex, скачивается и читается.
6. Elsevier возвращает записи через ScienceDirect Search или официальный Scopus
   fallback, если задан `ELSEVIER_API_KEY`.
7. Полный конвейер объединяет источники.
8. CSV, XLSX и `run_report.json` создаются и повторно читаются.

Живые тесты намеренно не входят в обычный CI: доступность внешних сервисов и их
лимиты не должны делать офлайн-сборку нестабильной.

## Интерпретация пустых полей

Пустое целевое поле означает «подтверждаемое значение не найдено в доступном
тексте», а не ноль и не отрицательный результат. Наличие 21 колонок не означает,
что издатель предоставляет все 21 значения для каждой публикации.

## Последний контрольный прогон

28 августа 2026 года:

- локально: 49 из 49 офлайн-проверок;
- живые источники: 14 из 14 проверок, без пропусков;
- полный живой прогон с настройками интерфейса по умолчанию
  (`200` на источник и полные тексты): 390 строк, CSV/XLSX созданы;
- чистый Linux-контейнер: образ собран, офлайн-проверки пройдены;
- HTTP smoke-тест: интерфейс отвечает из собранного контейнера;
- публичный Connect Cloud smoke-тест: приложение открывается без авторизации,
  ограниченный поиск вернул 6 строк из PubMed, ScienceDirect/Scopus и OpenAlex;
- `renv::status()`: зависимости согласованы с lock-файлом.

Предоставленный Elsevier API key принят сервисом, но не имеет разрешения на
ScienceDirect Search. Контрольный прогон поэтому использовал предусмотренный
официальный Scopus fallback; это отражается в `retrieval_method`.
