6. JSON скачан кнопкой браузера, прочитан функцией импорта и затем загружен обратно через видимую кнопку Browse в опубликованное приложение. Появился статус «Архив открыт: 6 статей».

Они сохранены в журнале; текущий интерфейс учитывает любые предупреждения при показе статуса «Готово с ограничениями».
