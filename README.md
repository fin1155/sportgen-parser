# SportGen Parser

Локальное приложение и CLI-конвейер для поиска исследований по спортивной
генетике, объединения метаданных и экспорта проверяемой таблицы в CSV/XLSX.

## Что работает

- PubMed через официальный NCBI E-utilities (`rentrez`), с history-пагинацией;
- Elsevier: ScienceDirect Search V2, а если ключ не имеет этого разрешения —
  официальный Scopus Search с фильтром `PUBLISHER(Elsevier)`;
- русскоязычные и российские публикации через OpenAlex с cursor-пагинацией и
  локальным фильтром `генетика AND спорт/физическая активность`;
- необязательный диапазон года публикации, включая только нижнюю или только
  верхнюю границу, одинаково применяемый ко всем включённым источникам;
- Crossref только для осторожного дополнения DOI и библиографии;
- объединение по DOI/PMID/нормализованному названию и удаление дублей;
- гены по словарю HGNC, rsID с числовой сортировкой (`rs2` раньше `rs10`);
- 44 научных поля из аннотаций, PMC и доступных открытых текстов, включая период исследования, группы, спорт, эффектный аллель и ссылки на данные;
- исходные фрагменты в `extraction_evidence` и качественный статус проверки в `extraction_confidence` (не вероятность);
- интерактивный интерфейс, CLI, CSV/XLSX и JSON-отчёт запуска;
- настройка состава и порядка столбцов таблицы с одинаковым применением к
  экрану, CSV и XLSX.
- переход к статье одним кликом по названию, PMID, DOI или явной ссылке.

eLIBRARY не парсится напрямую: у сервиса нет стабильного публичного API, а
автоматизация сайта зависит от CAPTCHA и может нарушать ограничения сервиса.
OpenAlex используется для поиска российских и русскоязычных публикаций; его покрытие не совпадает с eLIBRARY. Crossref не считается отдельным поисковым источником.

## Быстрый запуск

Требуется R 4.4 или новее.

```sh
Rscript install_packages.R
Rscript launch_app.R
```

Или используйте системный файл запуска:

- Windows: `launch_app.bat`;
- macOS: `launch_app.command`;
- Linux: `launch_app.sh`.

После запуска откроется локальный адрес `http://127.0.0.1:3838`. Данные и ключи
не отправляются на отдельный сервер приложения.

CLI-запуск полного конвейера:

```sh
Rscript run_all.R
```

Результаты создаются в `out/articles.csv`, `out/articles.xlsx` и
`out/run_report.json`, а также `out/research_archive.json`,
`out/associations.csv` и `out/evidence_summary.csv`.

## API-ключи

Создайте личный `.Renviron` по примеру `.Renviron.example` или задайте переменные
окружения перед запуском:

```sh
export ELSEVIER_API_KEY='ваш_ключ'
export NCBI_API_KEY='необязательно'
export OPENALEX_API_KEY='необязательно'
export CROSSREF_MAILTO='you@example.org'
```

Для интерфейса Elsevier-ключ можно ввести в поле пароля. Он живёт только в
текущем сеансе и не записывается в проект. Никогда не коммитьте `.Renviron`.

Ключ Elsevier может быть действительным, но не иметь права на ScienceDirect
Search. Это не ошибка ключа: приложение автоматически переключается на доступный
официальный Scopus Search и отмечает способ получения в `retrieval_method`.

## Запросы и лимиты

Для обычного запуска запросы менять не нужно. В интерфейсе они находятся во
вкладке `Запросы · необязательно`, разделены по источникам и свёрнуты по
умолчанию. Кнопка `Вернуть исходные` отменяет изменения текущего сеанса.

Для постоянного изменения проекта запросы хранятся в файлах:

- `config/query.txt` — PubMed;
- `config/query_sciencedirect.txt` — Elsevier;
- `config/query_openalex.txt` — русскоязычный OpenAlex.

Параметры источников находятся в `config/settings.json`. Значение
`max_records = 0` означает проход до предела конкретного API. Реализована
пагинация, а отчёт запуска сохраняет число полученных и заявленных источником
результатов. Ограничения самих API не обходятся.

В блоке `Год публикации (необязательно)` можно указать оба года или только один:

- `С: 2020`, `По: 2024` — публикации с 2020 по 2024 год включительно;
- только `С` — публикации не старше указанного года;
- только `По` — публикации не позднее указанного года;
- оба поля пустые — поиск без ограничения по году.

Диапазон передаётся непосредственно PubMed, Elsevier и OpenAlex, а полученные
строки дополнительно проверяются локально. В `run_report.json` сохраняются
границы, использованные в запуске.

Словарь генов содержит официальные символы HGNC и обновляется командой:

```sh
Rscript tools/update_hgnc_symbols.R
```

## Темы исследования

В разделе **«Поиск и фильтры»** доступны пять тем:

- Спортивная генетика — прежние запросы и дополнительный тематический фильтр.
- Заболевания — пример поиска биомаркеров, механизмов и лечения.
- Клеточные исследования — клеточные линии, культуры и органоиды.
- МикроРНК — miRNA, lncRNA, circRNA, мишени и экспрессия.
- Свободный запрос — введите свою тему для каждого выбранного источника.

Выбор темы подставляет редактируемые примеры запросов и набор колонок. Это
отправная точка, а не исчерпывающая стратегия систематического обзора: уточните
нужное заболевание, клеточную линию, молекулу или условия эксперимента.
Спортивный фильтр не применяется к другим темам. Для OpenAlex можно выбрать
российские/русскоязычные публикации или все страны и языки. Crossref дополняет
библиографию; его временная недоступность не прерывает поиск.

В CLI тема задаётся полем `research_profile` в `config/settings.json`:
`sports`, `diseases`, `cells`, `rna` или `general`. Собственные запросы можно
передать аргументом `queries` функции `run_pipeline()`.

## Настройка таблицы

Во вкладке **«Настроить таблицу»** — 69 колонок в девяти сворачиваемых группах.
Отмечайте поля галочками, выбирайте группу целиком, ищите колонку по названию
или используйте готовые наборы. «Свернуть всё» и «Развернуть всё» управляют
списком групп. Порядок выбранных полей меняется перетаскиванием или кнопками
вверх/вниз, в том числе с клавиатуры и на телефоне.

Предпросмотр показывает первые три статьи; до поиска отображаются явно
обозначенные условные данные. Кнопка **«Применить к таблице»** одновременно
меняет экран и CSV/XLSX. Пустой черновик разрешён, но применить его нельзя;
«Отменить изменения» возвращает текущий набор.

**«Мои шаблоны»** сохраняет до 30 собственных наборов в этом браузере. Их можно
скачать в JSON и открыть на другом компьютере. Последний применённый набор
восстанавливается после перезагрузки. API-ключи и статьи в шаблоны не входят.
JSON-архив исследовательского сеанса также сохраняет применённые колонки.

Результаты занимают всю ширину окна. Поиск и его группы сворачиваются; после
успешного запуска панель поиска закрывается автоматически. У таблицы есть
поиск, сортировка по заголовку, сворачиваемая строка фильтров по колонкам,
компактные строки и режим **«На весь экран»** с выходом по Escape.

По умолчанию CSV/XLSX учитывают отфильтрованные строки и их сортировку, а не
только текущую страницу. Снимите галочку под таблицей для выгрузки всех статей.
При нуле совпадений CSV содержит только заголовки. JSON-архив всегда сохраняет
полный исследовательский сеанс.

## Новые научные поля

Добавлены заболевание, подтип, стадия; клеточная линия, тип клеток, ткань,
организм и модель; miRNA, lncRNA, circRNA, ген-мишень и экспрессия; воздействие,
доза, длительность, контроль и метод эксперимента.

Извлечение использует ограниченные словари и правила. Для чисел и связей
сохраняются исходные предложения, чтобы не потерять единицы, отрицания и
принадлежность к группам. Несколько клеточных линий или молекул в статье не
разворачиваются в выдуманные пары экспериментов. Одна строка — одна статья.
Словари не охватывают все заболевания и линии; ненайденное значение можно
проверить и внести вручную. Каждое извлечённое новое поле имеет основание.

Старые JSON-архивы открываются с пустыми новыми колонками. Повторное извлечение
из сохранённых текстов может заполнить их без сети; подтверждённые значения
сохраняются. Таблица SNP-ассоциаций и её сводка по-прежнему относятся к SNP.

## Проверка извлечения и работа без сети

- «Ассоциации»: отдельные фрагменты со связями SNP, аллеля, фенотипа, модели и статистики; неоднозначные числа не назначаются автоматически.
- «Проверка»: значение, исходное основание, доступный текст, подтверждение поля и отмена последней проверки.
- «Доказательства»: предварительный профиль и сводка публикаций. Это не GRADE и не EvidenceGrade; [решение по OpenEvidence](docs/OPEN_EVIDENCE.md).
- «Архив»: переносимый JSON с текстами и историей, импорт и повторное извлечение без сети. Подтверждённые поля сохраняются.

CSV содержит выбранные колонки. На первом листе XLSX — тот же набор; другие листы содержат ассоциации, сводку и журнал ручной проверки. JSON сохраняет весь сеанс, независимо от видимых колонок. Скачивайте архив перед закрытием страницы или новым поиском: сеанс не записывается на сервер автоматически. Ключи не включаются в экспорт запуска.

## Проверка

Офлайн-набор не обращается к сети и проверяет парсеры, дедупликацию, сортировку,
извлечение, ложные совпадения, доказательства и экспорт:

```sh
Rscript tests/run_tests.R
Rscript tests/validate_corpus.R
Rscript tests/server_flow.R
```

Новые темы проверяются отдельным живым набором:

```sh
Rscript tests/live_flexible.R
```

Браузерные сценарии (Python Playwright и Chromium) описаны в
`tests/browser_flow.py`; им передаётся JSON-архив с синтетической фикстурой.

Живая smoke-проверка обращается к PubMed, OpenAlex и Crossref; Elsevier
проверяется, если задан ключ:

```sh
Rscript tests/run_live_tests.R
```

Тот же офлайн-набор запускается GitHub Actions на Windows, macOS и Linux.
Подробный протокол находится в `docs/VALIDATION.md`.
Сверка каждого пункта исходной задачи находится в `docs/TASK_AUDIT.md`.

## Docker

Docker позволяет запустить одинаковое окружение на любой ОС:

```sh
docker compose up --build
```

Откройте `http://localhost:3838`. Ключи передаются контейнеру только через
переменные окружения или локальный `.env`, который исключён из Git.

## Публичное веб-приложение без Docker у пользователей

Обновлённая версия опубликована в Posit Connect Cloud. Основная ветка — `main`;
публикация выполняется автоматически после push. [Протокол релиза 2.0](docs/DEPLOYMENT_V2.md):

**[Открыть SportGen Parser](https://01a0453f-1564-0962-c6b3-e0e7a8fbbdb6.share.connect.posit.cloud)**

Пользователь открывает обычную HTTPS-ссылку и ничего не устанавливает. Docker и
R на его компьютере не нужны. Ключ Elsevier хранится в зашифрованной переменной
окружения Connect Cloud и отсутствует в GitHub.

Для повторной публикации своей копии:

1. Подключите публичный GitHub-репозиторий в Connect Cloud.
2. Выберите тип `Shiny`, ветку `main` и основной файл `app.R`.
3. Добавьте `ELSEVIER_API_KEY` в разделе секретных переменных приложения.
4. Нажмите `Publish`.

Зависимости и поддерживаемая версия R описаны в `manifest.json`. Данные каждого
веб-сеанса хранятся раздельно и отдаются через кнопки скачивания; приложение не
пишет пользовательскую выдачу в общий каталог на сервере.

## Ограничение достоверности

Программа не обходит платный доступ. Поля, которых нет в метаданных, аннотации,
PMC или другом открытом полном тексте, остаются пустыми. Эвристически извлечённые
значения предназначены для предварительной разметки и должны быть проверены
исследователем по `extraction_evidence` перед статистическим анализом.

Локальные файлы запуска кроссплатформенны, но не являются подписанными
самодостаточными установщиками: без Docker на компьютере должен быть установлен R.
Создание подписанных `.exe`/`.dmg`/пакетов Linux требует отдельных сборочных и
подписывающих сертификатов владельца релиза.
